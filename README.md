# CMA-RL
This repository contains the implementation of **CMA-RL**, a cross-modal semantic alignment-guided reinforcement learning multi-hop reasoning framework (CMA-RL).

## ⚠️ Implementation Availability
The full source code of this project will be made publicly available **upon the formal publication of our paper**.

## Overview
Our main contribution lies in extending multi-hop reasoning ensembles to multi-hop question-answering systems, identifying the challenges encountered in this extension, and providing a solution based on contrastive learning.
